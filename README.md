# Transformer IDS

Intrusion detection system based on transformer sequence modeling.

## Project layout

- `data/`: raw and processed datasets
- `notebooks/`: exploratory analysis and baseline experiments
- `src/`: reusable data, modeling, training, and evaluation code
- `experiments/runs/`: checkpoints and logs for each run
- `reports/figures/`: generated charts and analysis artifacts

## Getting started

1. Create and activate a Python environment.
2. Install dependencies with `pip install -r requirements.txt`.
3. Run the notebooks in order.
4. Use `python -m src.train` for model training once the pipeline is configured.
